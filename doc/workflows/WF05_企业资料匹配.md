# WF05 企业资料匹配

DSL `workflows/WF05.yml`。开始节点接收 `project_id`，可填 `{"as_of":"2026-11-16"}`。代码节点校验日期。HTTP 节点调用 `POST /v1/workflows/WF05/run`。输出节点返回 `status`、`http_status`、`result_json`。

业务服务用同版本的要求、评分矩阵和截至日期查询已审核、适用且有效的企业证据。记录资料版本、来源、有效期和缺失状态。有匹配条目时由独立审核人员复核 `match/latest`，确认候选资料的适用性。历史标书作为工法和表达经验。完整商务标表单编制见 WF07 后续设计。

测试当前有效证照和同类已过期证照。有效证照可出现于候选结果，只有过期证照时该项显示缺资料。使用不同租户验证资料隔离。核对返回的归档引用是否能定位到证据原件版本。
