# WF07 商务资信编制 · 后续设计

后续工作流的开始节点接收项目 ID、已审核的资料匹配记录及商务表单模板版本。前置条件是项目招标要求和企业证明均已核验。

流程拟由代码节点检查必填字段及证照有效期，由 HTTP 节点调用授权的企业证据接口和商务套版服务，以项目、本企业及材料版本筛选。段落辅助说明采用本地模型。证照名称、编号、有效期及金额类字段通过结构化资料进入模板。审核人检查固定格式、人员业绩关联、保密和签章要求。输出商务 DOCX 草稿和缺件表。

测试设计包括证件过期、人员不适用、企业材料缺页和项目模板变更。第一阶段实现 WF05 匹配和证据引用，WF07 接口和 DSL 作为后续扩展。
