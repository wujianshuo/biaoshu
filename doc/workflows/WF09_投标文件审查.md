# WF09 投标文件审查

DSL `workflows/WF09.yml`。开始节点接收 `project_id` 和 `{}`。代码节点校验输入，HTTP 节点调用 `POST /v1/workflows/WF09/run`，结果返回 `status`、`http_status`、`result_json`。

后台读取编制章节、条款/评分矩阵、最新证据引用和项目事实，给出缺项、引用异常、关键值和版本冲突。人工专业复核覆盖施工可实施性、暗标及项目电子投标要求。业务记录 `audit/latest` 保存问题和复核状态。

用含旧工期或无效引用的技术标试跑，报告应标出相应问题。修正后重新审查，由审核人按新版本确认。保存旧报告以保留可追踪的整改记录。
