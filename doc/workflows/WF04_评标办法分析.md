# WF04 评标办法分析

DSL `workflows/WF04.yml`。开始节点接收 `project_id` 和 `{}`。代码节点校验参数，HTTP 节点调用 `POST /v1/workflows/WF04/run`，输出节点返回 `status`、`http_status`、`result_json`。

后台从审核通过的招标解析版本生成评分响应矩阵，评分项来源关联当前项目原件。保留评分条件、分值和所需材料，未确认分值保持待核，评分模板不能增加招标文件未规定的得分项。成果 XLSX 对应项目产物 `scores`。

测试招标正文含技术评分分值的项目，核对每个有分数的条目是否指向源段。审核缺失或解析版本失效时检查是否返回可解释的业务错误。
