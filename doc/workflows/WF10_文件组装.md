# WF10 文件组装

DSL `workflows/WF10.yml`。开始节点接收 `project_id` 和可选的 `request_json`。可设 `mode` 为 `draft` 或 `reviewed`，草稿也可传入 `template_document_id`，指定已归档确认的项目 Word 模板。设 `include_pdf:true` 时调用配置的本地 LibreOffice。HTTP 节点调用 `POST /v1/workflows/WF10/run`，返回业务状态和成果引用。

后台按项目章节顺序生成 Word 技术标草稿。`draft` 供校阅，`reviewed` 要求满足人工复核门槛及当前版本审核状态。使用项目带鉴权的产物接口下载 `technical-draft` 或 `technical-reviewed`。正式电子签章、平台加密和交易平台专有格式由对应制作软件处理。

测试先生成并下载草稿。随后请求 `reviewed`，未完成审核时应被拒绝。对当前版本各章、`audit/latest` 和 `artifact/technical-draft` 执行人工审批后，再请求并查看成果版本。检查标题层级、正文顺序和 Word 打开情况，保留下载记录。
